01ClimaPanel智能暖通控制面板

围绕 ESP32-S3 开发暖通触控控制器。将本机与 CAN 总线房间数据接入同一条控制链路，连接用户设定、温湿度感知与 0–10 V 风机盘管输出。

实现内容

  • 适配 RGB / ST7701S 显示与触摸驱动，使用 LVGL 构建暖通交互页面。
  • 整合 SHT41 采集、房间选择、动态设备 ID 与 CAN 房间缓存。
  • 实现 PI 温控、积分抗饱和、回差处理，以及温湿度联动除湿和防过冷逻辑。
  • 实现 BLE OTA 的偏移检查、异步写入、SHA-256 校验与启动确认。

工程思考

  • RGB 显示与 PSRAM / DMA 协同：双帧缓冲、帧完成同步、分阶段启屏与显示恢复任务。
  • 控制状态切换：切换房间或冷热模式时重置控制状态，明确正常温控与除湿接管关系。
  • 让 UI、通信和控制使用一致的房间数据语义，避免把缺失字段当作有效测量值。

温控采用 PID 框架，当前参数使用 PI（D = 0）。除湿策略为温湿度联动与防过冷控制。

02ClimaPower面板电源与接口底板

将电源与接口做成独立底板，围绕暖通面板的供电、控制信号和外部连接展开硬件设计。

实现内容

  • 电路包含市电整流、隔离反激供电及偏置路径。
  • 组织 12 V / 24 V 输入汇流和 3.3 V 降压网络。
  • 引出 CAN、0–10 V 及继电器控制等板间信号。

工程思考

  • 沿整流、开关、变压器、次级整流与降压逐级梳理能量路径。
  • 结合面板和底板边界检查供电、接口回流与信号连接，关注启动及上电状态。
03AirBox新风与风机联动控制

基于 ESP32-S3 组织新风控制流程，接入 CAN 房间状态、CO₂ 信息与温度采集，驱动风机、风阀及相关输出。

实现内容

  • 适配 GP8403 模拟输出与 PWM 输出，连接风机和风阀控制。
  • 按选择的 BOX 处理控制信息，参与多设备 CAN 联动。
  • 将 DS18B20 采集交给独立任务，发布带时间戳的数据快照。
  • 实现 BLE 配网与现场调试入口，并接入设备端 OTA 模块。

工程思考

  • 通过独立采集任务减少多个业务任务争用 1-Wire 总线。
  • 为房间模式建立有效期，过期后撤销新风激活条件并重新计算输出。
  • 把环境数据、设备模式和输出计算拆开，方便定位异常来自采集、通信还是控制。
04ControlBox多区域执行与数据网关

基于 ESP32-S3 实现区域 B–I 的 8 路继电器控制，处理 BOX 配对与 ClimaPanel 直控场景，并为 BLE 配置与 MQTT 上报提供房间数据。

实现内容

  • 实现区域 B–I 输出、汇总输出与制冷 / 制热状态输出。
  • 组织 BOX 在线状态与 Clima 直控仲裁，明确输出命令来源。
  • 将 CAN 接收、协议解析与房间同步分为独立任务。
  • 建立包含有效位、字段时间戳与版本号的房间缓存，支持 BLE Wi-Fi 配网和 MQTT 上报。

工程思考

  • 先接收和缓存总线数据，再进入业务仲裁，降低网络操作对 CAN 处理的影响。
  • 区分字段有效性与房间在线状态，让消费者能够判断数据是否可用。
  • 通过保留消息、遗嘱消息和重连补发支持上位系统获取设备状态。

MQTT 上报包含设备状态与房间快照，支持断线后的重新同步。

05Modbus 网关CAN ↔ RS-485 协议转换

基于 STM32F103 与 FreeModbus 连接暖通 CAN 系统和 Modbus RTU 上位系统，完成房间状态、温湿度和设定参数的应用层映射。

实现内容

  • 将 CAN 状态映射到寄存器，并将合法写入转换成 CAN 控制命令。
  • 用有效状态区分未知数据与实际为零的数据。
  • 实现 FC16 多寄存器写入预检，包括地址、取值和发送队列容量。
  • 将从站地址保存到预留 Flash 区域，回读确认后等待当前应答结束再切换。

工程思考

  • 中断快速入队、主循环按预算解析，兼顾总线突发和 Modbus 应答。
  • 通过整批预检减少多寄存器操作中部分命令先行生效的问题。
  • 配套整理寄存器定义、协议映射和对接手册，让第三方集成有据可查。

当前工程使用 9600 8N1。寄存器写入成功和现场执行器动作完成是不同层级的状态。

06索热设备助手蓝牙配网、调试与固件升级

基于原生微信小程序实现设备近场交互，将 ESP32 端的配网、状态查询与调试协议转化为现场可操作的页面；新版本加入 ClimaPanel BLE OTA 流程。

实现内容

  • 通过 BLE 发现和连接设备，由设备扫描 Wi-Fi，小程序展示网络列表并下发配置。
  • 按设备类型进入 AirBox、新风或 ControlBox 的监控与调试页面。
  • 展示 ControlBox 区域 B–I 状态，处理 BOX 配对与设备确认。
  • 为 ClimaPanel 提供固件下载、完整性检查、蓝牙分片传输和升级进度反馈。

工程思考

  • 按设备类型与新风型号组织页面及参数，减少无效调试入口。
  • 区分配置已发送、设备确认与操作完成，让反馈与实际处理阶段一致。
  • 围绕 BLE 分片、偏移同步与中断恢复组织 OTA 状态流程。

ClimaPanel OTA 采用带偏移的分片协议，结合 SHA-256 校验与升级进度反馈。
