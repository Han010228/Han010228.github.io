01ClimaPanel智能暖通控制面板

我负责面板电路、ESP32-S3 固件和触控界面。面板读取本机和 CAN 房间的温湿度，根据设定值控制风机盘管的 0–10 V 输出。

做了什么

  • 适配 RGB / ST7701S 显示与触摸驱动，使用 LVGL 构建暖通交互页面。
  • 整合 SHT41 采集、房间选择、动态设备 ID 与 CAN 房间缓存。
  • 实现 PI 温控、积分抗饱和、回差处理，以及温湿度联动除湿和防过冷逻辑。
  • 实现 BLE OTA 的偏移检查、异步写入、SHA-256 校验与启动确认。

关键处理

  • 适配 RGB 屏、触摸和 SHT41 传感器。
  • 编写多房间 CAN 数据处理和房间选择逻辑。
  • 实现 PI 温控、除湿控制和 BLE 固件升级。

温控采用 PID 框架，当前参数使用 PI（D = 0）。除湿策略为温湿度联动与防过冷控制。

02ClimaPower面板电源与接口底板

这块底板给 ClimaPanel 供电，并提供 CAN、0–10 V 和继电器等接口。电路包含隔离反激、12 V / 24 V 输入汇流和 3.3 V 降压。

做了什么

  • 电路包含市电整流、隔离反激供电及偏置路径。
  • 组织 12 V / 24 V 输入汇流和 3.3 V 降压网络。
  • 引出 CAN、0–10 V 及继电器控制等板间信号。

关键处理

  • 设计市电输入、隔离反激和次级整流电路。
  • 设计 12 V / 24 V 汇流、3.3 V 降压和板间连接。
03AirBox新风与风机联动控制

AirBox 接收 CAN 房间状态，读取 CO₂ 和 DS18B20 温度数据，控制风机、风阀等输出；支持 BLE 配网和调试。

做了什么

  • 适配 GP8403 模拟输出与 PWM 输出，连接风机和风阀控制。
  • 按选择的 BOX 处理控制信息，参与多设备 CAN 联动。
  • 将 DS18B20 采集交给独立任务，发布带时间戳的数据快照。
  • 实现 BLE 配网与现场调试入口，并接入设备端 OTA 模块。

关键处理

  • 实现 PWM 和 0–10 V 风机、风阀输出。
  • 把 DS18B20 采集放入独立任务，发布带时间戳的读数。
  • 处理 CAN 房间模式超时，避免继续使用过期状态。
04ControlBox多区域执行与数据网关

ControlBox 管理区域 B–I 的 8 路继电器，接收 CAN 房间数据，处理 BOX 配对，并通过 MQTT 上报设备和房间状态。

做了什么

  • 实现区域 B–I 输出、汇总输出与制冷 / 制热状态输出。
  • 组织 BOX 在线状态与 Clima 直控仲裁，明确输出命令来源。
  • 将 CAN 接收、协议解析与房间同步分为独立任务。
  • 建立包含有效位、字段时间戳与版本号的房间缓存，支持 BLE Wi-Fi 配网和 MQTT 上报。

关键处理

  • 编写区域 B–I 继电器输出与控制来源仲裁。
  • 把 CAN 接收、解析和房间同步拆分为独立任务。
  • 维护房间有效位和更新时间，供 BLE 与 MQTT 使用。

MQTT 上报包含设备状态与房间快照，支持断线后的重新同步。

05Modbus 网关CAN ↔ RS-485 协议转换

基于 STM32F103 和 FreeModbus，把 CAN 房间数据映射为 Modbus RTU 寄存器，并将合法的寄存器写入转换为 CAN 命令。

做了什么

  • 将 CAN 状态映射到寄存器，并将合法写入转换成 CAN 控制命令。
  • 用有效状态区分未知数据与实际为零的数据。
  • 实现 FC16 多寄存器写入预检，包括地址、取值和发送队列容量。
  • 将从站地址保存到预留 Flash 区域，回读确认后等待当前应答结束再切换。

关键处理

  • 定义房间状态、温湿度和参数的寄存器映射。
  • 对 FC16 多寄存器写入先整体检查，再执行命令。
  • 把 Modbus 从站地址存入预留 Flash 页。

当前工程使用 9600 8N1。寄存器写入成功和现场执行器动作完成是不同层级的状态。

06索热设备助手蓝牙配网、调试与固件升级

原生微信小程序通过 BLE 连接设备，完成 Wi-Fi 配置、状态查看和现场调试；新版加入 ClimaPanel 蓝牙固件升级。

做了什么

  • 通过 BLE 发现和连接设备，由设备扫描 Wi-Fi，小程序展示网络列表并下发配置。
  • 按设备类型进入 AirBox、新风或 ControlBox 的监控与调试页面。
  • 展示 ControlBox 区域 B–I 状态，处理 BOX 配对与设备确认。
  • 为 ClimaPanel 提供固件下载、完整性检查、蓝牙分片传输和升级进度反馈。

关键处理

  • 由设备扫描 Wi-Fi，再在小程序中选网络并下发密码。
  • 按 AirBox、新风和 ControlBox 类型显示对应的监控与调试页面。
  • 实现 ClimaPanel 固件下载、SHA-256 校验和 BLE 分片升级。

ClimaPanel OTA 采用带偏移的分片协议，结合 SHA-256 校验与升级进度反馈。
